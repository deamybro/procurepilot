# Product

ProcurePilot is a procurement operating layer for digital-service agents. The
user supplies an outcome, budget, token and approval preference. The system
builds an explainable plan, makes consequential costs visible, coordinates
specialists and returns one result.

The MVP targets hackathon demonstration and learning. Its business-model example
adds a visible 0.25 USDC orchestration fee. Demo fees and provider payments are
simulated; testnet fees remain disabled until a payout route is configured and
approved.
