# Free Build Guide

The full scripted demo needs only Node.js and open-source npm packages:

```bash
npm install
npm run demo
npm run dev
```

No API key, wallet, RPC purchase, database, vector store, paid search, IPFS,
analytics, authentication, domain or mainnet funds are required. Optional
Gemini access uses a free-tier key. Optional real demonstrations use public GOAT
testnet3 infrastructure and faucet tokens.
